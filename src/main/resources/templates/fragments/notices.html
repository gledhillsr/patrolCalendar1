Reading the example: the first shift has a Label as well as its times, so the calendar shows the label (dir). The second has times and no label, so it shows the start time (8:00). The third has a label and no times at all, so it shows mentee.
That third shift will not sync to a personal calendar — a shift needs both a start and an end time before it can be sent, so it is simply left out. Give it times and it syncs like the others: the calendar still shows mentee, because a label is always what appears when there is one.
